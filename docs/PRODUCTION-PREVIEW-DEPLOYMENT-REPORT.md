## Rollback

Ne pas désactiver `noindex` pour un rollback partiel. Pour revenir à l'état pré-V1, utiliser `pre-37110295574` : via SSH autorisé, vérifier `SHA256SUMS`, restaurer `wordpress.sql.gz` avec `wp db import`, puis extraire `lemoulindelaure-child.tgz` à sa place après avoir conservé la copie actuelle. `wp-config.php` est sauvegardé pour comparaison et restauration si nécessaire. Le fichier `robots.txt` antérieur au correctif est conservé comme `robots-before.txt` dans `pre-37112813684`; son retour bloquerait la lecture des balises noindex et doit être délibéré. Purger LiteSpeed puis vérifier `/`, thème actif, menus et robots. Pour revenir seulement à la dernière prévisualisation saine, utiliser le snapshot final ci-dessous, qui contient DB, thème, configuration et `robots.txt`. Les snapshots `before-content-*` permettent un retour DB juste avant chaque application. Le workflow de thème fait aussi un rollback automatique de son dossier si l'installation échoue. Les sauvegardes restent privées sur le serveur ; les identifiants sont les seuls éléments consignés ici.

## QA finale et limites

Edge headless a ouvert les douze pages à **375, 768, 1024 et 1440 px** sous `prefers-reduced-motion: reduce` : 48 vues, un H1 par page, aucune image cassée, erreur console ou largeur horizontale excessive. Captures des pages Accueil, hub, Contact et Booking inspectées après une seconde passe. Le premier Tab cible « Aller au contenu » ; le menu mobile s'ouvre avec `aria-expanded=true` et le lien Booking est visible ; les quatre panneaux du hub ont chacun un lien visible sous reduced motion. Les liens internes publics couvrent les douze chemins ; un balayage HTTP final renvoie 200/noindex pour chacun. Les URL `Sample Page` et `Hello World` ne répondent plus comme pages publiées. Le HTML public n'affiche ni `TEST LOCAL` ni la qualification Laila non prouvée. Les 27 URL d'assets thème de l'accueil sont HTTPS ; aucune URL thème HTTP n'y reste. Les fichiers PHP du thème et l'installateur passent `php -l`; `git diff --check` est propre. Les tests locaux détaillés Gutenberg, clavier, reduced motion et plugins sont consignés dans les rapports d'intégration précédents.

Le test live ne peut pas valider l'envoi d'un formulaire ou une réservation : le destinataire, les modalités des quatre services et les notifications réelles manquent. L'absence de canonicals dans la prévisualisation noindex a été constatée ; titres, descriptions, canonicals, schema, sitemap, consentement Complianz et mise en index relèvent de la validation finale avant ouverture aux moteurs. Les pages ne doivent pas passer à `index` avant ces contrôles et la validation du contenu client. La navigation clavier et la mise en page des vrais modules Forminator/Timetics devront être recontrôlées après leur configuration.
