# Visual QA Checklist

Use after meaningful visual implementation.

## Brand
- [ ] Looks like the intended brand
- [ ] Active Master rules respected
- [ ] No accidental new font/palette/component system
- [ ] Distinctive idea is relevant, not decorative noise

## Hierarchy
- [ ] Page purpose is obvious
- [ ] Primary action has clear priority
- [ ] H1 and section hierarchy scan well
- [ ] Supporting content does not compete with primary content

## Desktop
- [ ] 1440px reviewed
- [ ] 1024px reviewed
- [ ] Max widths feel intentional
- [ ] Whitespace is balanced
- [ ] No oversized empty zones without purpose

## Tablet
- [ ] 768px reviewed
- [ ] Grid collapse is deliberate
- [ ] Navigation works
- [ ] Media cropping remains useful
- [ ] No awkward intermediate wrapping

## Mobile
- [ ] 375px reviewed
- [ ] H1 wraps naturally
- [ ] No horizontal overflow
- [ ] Touch targets are usable
- [ ] Buttons do not become awkward
- [ ] Cards/columns collapse intentionally
- [ ] Media remains legible
- [ ] Spacing has been redesigned, not merely shrunk

## States
- [ ] Hover
- [ ] Focus
- [ ] Active/pressed
- [ ] Disabled where applicable
- [ ] Error/success where applicable

## Accessibility
- [ ] Visible focus
- [ ] Semantic controls
- [ ] Contrast
- [ ] Labels/errors
- [ ] Color not sole state indicator
- [ ] Reduced motion supported

## Content robustness
- [ ] Longer headings
- [ ] Longer button labels
- [ ] Localization/text expansion
- [ ] Empty/large data states if relevant
- [ ] Long words/URLs

## Performance
- [ ] LCP asset strategy sane
- [ ] No unnecessary font
- [ ] No new layout shift
- [ ] No decorative heavy JS without reason
- [ ] Images sized/optimized appropriately

## Final critique
- [ ] Identify weakest visual decision
- [ ] Fix it or explain why it remains
- [ ] Remove unnecessary decoration
