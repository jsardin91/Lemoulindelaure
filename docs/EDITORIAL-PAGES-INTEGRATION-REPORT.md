## Architecture and editing

- `inc/editorial-page-patterns.php` registers `lmdl/le-jardin-v1`, `lmdl/a-propos-v1`, `lmdl/journal-v1`, and an optional `lmdl/jardin-profile-entry` draft. Insert one full-page pattern in each page at `/le-jardin/`, `/a-propos/`, `/journal/` and select **LMdL — Page V1**. All page copy, images, section groups and the Journal Query Loop are native Gutenberg blocks. The PHP file assembles the initial patterns; it does not own saved page content.
- `assets/css/pages/editorial.css` owns these three layouts and the native post reading view. `functions.php` loads it only for those three page slugs and singular posts. Astra still renders the header, menu and footer. No builder, custom React block, extra JS or CSS pipeline was added.
- Jardin intentionally ships as a useful empty state: purpose, editorial manifesto, transparency and paths back to the site. No fake professional, category or empty grid appears. The optional profile pattern is hidden by `lmdl-pattern-placeholder` until actual identity, activity, permission and approved contact details are supplied; remove that class only after review. Add Humains/Animaux sections only when they contain consented profiles.
- À propos uses the real brand emblem where Laure's portrait is still unavailable and a restrained original squirrel painting later in the story. An editor-only note explains the portrait replacement. The training sentence is conservative; exact school, duration and diploma wording remain unpublished pending evidence. It does not claim Laila Del Monte certification or extend that training to other services.
- Journal uses one native `core/query` for the six latest published `post` entries, date descending. The first entry leads visually; the others form an editorial list. Native pagination and `core/query-no-results` provide page two and an empty state. There are no public categories or hardcoded article teasers. Featured images, title, date and excerpt come from each post. Editorial control of the lead currently means publication order; pinning/curation would require a later approved editorial decision.
- `single.php` presents ordinary WordPress posts at `/journal/[slug]/` with H1, optional explicit excerpt, date, actual WordPress author display name, optional image/caption, editable article content and a return link. Only a post genuinely attributed to display name `Laure Moulin` links its author name to `/a-propos/`. Reading width is about 72ch CSS maximum (644 px measured at 1440). The child theme emits no Article JSON-LD; Rank Math remains the intended schema, metadata and canonical layer.
- `functions.php` adds the Journal rewrite and published post permalinks. After deploying code to **staging**, flush permalinks once in WordPress Settings → Permalinks or with WP-CLI, then verify page/post URLs and canonical tags. This was done only in the isolated local fixture. The Timetics bundle is dequeued on V1 template pages/native posts only if their content lacks a Timetics marker; booking pages retain it.
