# 21st Reference Study — Communication animalière

Status: **reference only**

Last updated: 2026-10-02

## Goal

Use 21st as a visual-pattern catalogue for a service detail page while preserving the Moulin brand and avoiding generic SaaS/medical design.

## Useful reference families

### Vertical How It Works Timeline

Catalogue:
https://21st.dev/community/components/s/landing-page
https://21st.dev/community/components/explore/timeline-ui-component

Use for:
- session/process explanation after Laure confirms the actual steps

Adaptation:
- restrained line/numbers
- no animated progress tracking
- mobile vertical by default

### About / About 3

Catalogue:
https://21st.dev/community/components/s/landing-page
https://21st.dev/community/components/explore/landing-page-components

Use for:
- expertise/training section composition
- image + credibility content

Adaptation:
- real Laure credentials only
- no fake stats
- no generic corporate team presentation

### Two-Column FAQ / FAQ Accordion

Catalogue:
https://21st.dev/community/components/s/faq
https://21st.dev/community/components/s/landing-page

Use for:
- communication animalière FAQ

Adaptation:
- accessible semantic accordion
- project palette
- source-approved answers only

### CTA / booking blocks

Catalogue:
https://21st.dev/community/components/s/cta

Use for:
- closing action hierarchy

Adaptation:
- one primary action: Prendre rendez-vous
- no scarcity/urgency gimmicks
- no sales countdown
- Timetics remains on dedicated booking page

## Explicitly rejected patterns

- price comparisons
- feature matrices
- medical clinic aesthetics
- “before/after” visuals
- star-rating blocks without real source data
- animated testimonial marquees
- symptom selectors
- urgency banners
