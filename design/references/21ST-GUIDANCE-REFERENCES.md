# 21st Reference Study — Guidance pour soi

Status: **reference only**

Last updated: 2026-10-02

## Goal

Support a light, editorial and spacious Guidance page without adopting generic “spiritual website” visual codes.

## Useful current 21st guidance

### Split-screen layout

Reference:
https://news.21st.dev/blog/split-screen-layout-components

Useful:
- two-column storytelling;
- crucial mobile rule: message first, image second in source order.

Adaptation:
- butterfly painting is visual side;
- no image-first mobile stack;
- avoid overdecorated image-card surfaces.

### Image catalogue / Editorial Collage Hero / Vertical Image Stack

Reference:
https://21st.dev/community/components/s/image

Useful:
- image grouping;
- controlled asymmetry;
- editorial negative space.

Adaptation:
- use only one or two supporting artwork crops at most;
- page should feel lighter than homepage;
- do not create a dense collage.

### Plain sections principle

Reference:
https://docs.21st.dev/blog/prebuiltui-components

Useful principle:
one or two sections can carry personality; the rest should be easy to read.

Adaptation:
- hero = visual identity moment;
- remaining page = calm editorial content;
- do not decorate every section.

### Feature-section guidance

Reference:
https://docs.21st.dev/blog/react-feature-section-components

Useful principle:
avoid generic equal-card claims and vague marketing statements.

Adaptation:
- do not turn “situations” into three invented benefit cards;
- source-backed prose wins.

## Explicitly rejected

- aurora/glowing gradients;
- tarot/oracle card UI;
- stars/constellations;
- animated particles;
- glassmorphism;
- “mystical” floating cards;
- fortune/prediction visual cues.

## Future 21st MCP search prompts

- airy editorial split hero
- minimal image stack
- calm editorial service page
- minimal faq
- plain content section
- soft CTA section

Preview first; never install before brand/content review.
