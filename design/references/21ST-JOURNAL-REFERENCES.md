# 21st Reference Study — Journal

Status: **reference only**

Last updated: 2026-10-02

## Primary guidance

Reference:
https://news.21st.dev/blog/react-blog-layout-components

Key principles adopted:
- index and article have different jobs;
- article reading measure ~60–75 characters;
- honest published/updated dates;
- real H1/H2/H3 structure;
- index can carry more visual design;
- article should prioritize reading.

## Useful component families

From 21st Blog collections:
- responsive blog grid;
- split image blog list;
- stacked heading/article preview;
- editorial featured story.

Adaptation:
- one featured article;
- secondary list;
- project palette;
- no glassmorphism.

## Rejected

- card-heavy “news portal” look;
- auto-moving article carousels;
- excessive tags;
- filters before content volume justifies them;
- infinite scroll by default;
- decorative article pages.
