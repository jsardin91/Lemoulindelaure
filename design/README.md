# Design Workspace

This folder stores project design inputs and review artifacts.

- `brand/` — client brand guidelines, logo rules, approved assets and a human-readable summary.
- `references/` — approved inspiration/reference captures and notes.
- `wireframes/` — wireframes and structure explorations.
- `reviews/` — visual QA notes, screenshots and review summaries.

Durable design rules belong in `../design-system/`, not here.

No final art direction should be created before the client brand guidelines arrive.
