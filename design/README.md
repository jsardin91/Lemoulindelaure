# Design Workspace

This folder stores project design inputs and review artifacts.

- `brand/` — approved/working brand guidance, logo rules, source assets and generated brand assets.
- `references/` — approved inspiration/reference captures and notes.
- `wireframes/` — wireframes and structure explorations.
- `reviews/` — visual QA notes, screenshots and review summaries.

Durable design rules belong in `../design-system/`.

## Current state

Visual foundations are approved and active as of 2026-10-02.

Before creating or changing page designs, read:
1. `brand/BRAND-GUIDELINES-WORKING.md`
2. `../docs/SITE-ARCHITECTURE.md`
3. `../design-system/MASTER.md`

Do not replace approved visual foundations with generic AI/tool output.
