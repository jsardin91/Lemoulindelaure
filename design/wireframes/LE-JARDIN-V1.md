# Le Jardin du Moulin — Page Wireframe V1

Status: **working design/content-architecture draft — waiting for real participants**

Last updated: 2026-10-02

URL:
`/le-jardin/`

## Client intention

The client brief states:

- different viewpoints do not have to oppose each other;
- they can meet, complement each other and open new paths;
- Laure wants to present experts and therapists encountered on her path;
- inclusion is subject to their agreement;
- each person can be introduced in one sentence with contact details;
- examples are split between humans and animals.

This is **not** a fifth accompaniment.

---

# Page job

Help visitors discover a small, curated network around Le Moulin de Laure.

The page must communicate:
- personal selection rather than marketplace scale;
- real people/professionals;
- complementarity;
- transparency;
- consent;
- easy access to direct contact information.

It should not imply:
- employment by Laure;
- formal partnership unless true;
- endorsement of every claim/method;
- that Laure provides the listed professional's service herself.

---

# Visual thesis

**A living garden of encounters.**

The page should feel:
- open;
- green;
- human;
- editorial;
- lightly organic;
- less “service conversion” focused than the rest of the site.

Use the garden metaphor through composition, spacing and subtle botanical motifs — not through a literal illustrated garden scene full of decorative clutter.

Palette emphasis:
- Cream
- Paper
- Leaf green
- Teal
- Ink
- small Antique gold details

# 3. Two garden paths

The source distinguishes:
- **Pour les humains**
- **Pour les animaux**

This distinction is meaningful and can structure the page.

## Desktop

Two clear editorial navigation blocks:
- Humains
- Animaux

These are category anchors, not service cards.

Possible examples from the brief:
Humans:
- intermédiaire chamanique;
- QI Cleansing;

Animals:

- other professionals to be supplied.

# 4. Professional/person listing

## Core principle

Only real, consented entries.

Minimum entry data:
- name;
- activity/title in clear language;
- one short sentence describing what they do;
- contact link/details approved for publication.

Preferred additional data when available:
- real portrait/logo;
- website/professional profile;
- location/remote information if supplied.

Do not invent:
- photo;
- qualifications;
- ratings;
- testimonials;
- years of experience;
- service claims;
- social profiles.

## Layout direction

Use a **magazine/profile list**, not an ecommerce marketplace.

Desktop options:
- staggered 2-column profile list;
- one featured profile + smaller profiles;
- alternating image/text only if the number of entries remains small.

For each entry:
- real image if supplied;
- name as heading;
- activity;
- one sentence;
- external/contact link.

Avoid:
- generic white card wall;
- rating stars;
- price badges;
- “Book” buttons;
- “verified” badges unless there is an actual verification process.

## External links

Make destination clear:
- “Découvrir son activité”
- “Site”
- “Contacter …”

External links should not masquerade as Moulin booking CTAs.

# 5. Consent and relationship clarity

Recommended editorial note:
- people are presented with their agreement;
- wording should clarify the nature of the relationship if needed.

Exact public disclaimer should be validated later.

Do not label everyone:
- partner;
- therapist of Le Moulin;
- recommended medical professional;
unless factually correct and approved.

---

# 6. Empty / low-content launch state

If there are no approved professionals at launch:

Do **not** publish a page with fake placeholders.

Options:
1. keep page draft/private until entries exist;
2. publish only the manifesto if Laure explicitly wants the concept visible, with no “coming soon” grid;
3. remove from primary navigation temporarily if empty.

Preferred:
do not expose an empty directory.

If one category has zero entries:
hide the empty category.

---

# 7. Optional contextual links

Once real profiles exist, the page can link contextually from:
- Communication animalière -> animal professionals;
- other accompaniment pages -> human professionals where genuinely relevant.

Do not automate recommendations or suggest a professional based on sensitive user data.

# 8. Closing section

# Responsive

Desktop:
- editorial/staggered profile presentation.

Tablet:
- 2-column if images/content remain comfortable.

Mobile:
- 1 profile per row;
- name/activity immediately visible;
- image before or beside content depending crop;
- external link 44px+ target.

No hover-only details.

---

# Accessibility

- person name/activity must be text, not embedded in images;
- if a portrait sits next to a visible person's name, alt can be empty to avoid duplicate screen-reader announcement;
- external link text must identify destination;
- do not rely on portrait/color to distinguish human vs animal categories;
- visible keyboard focus;
- no auto-moving profile carousel.

---
