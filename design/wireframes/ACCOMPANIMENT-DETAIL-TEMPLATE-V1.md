# Individual Accompaniment Page Template V1

Status: **working structural template**

Last updated: 2026-10-02

Purpose: establish the common UX/content skeleton for the four accompaniment detail pages without forcing identical visual composition.

Applies to:
- Communication animalière
- Accompagnement énergétique animalier
- Connexion avec les défunts
- Guidance pour soi

## Principle

The four pages must feel like members of the same family, but each retains its own animal/element/artwork emphasis.

Shared:
- header/navigation
- typography
- global spacing
- content hierarchy
- booking CTA vocabulary
- FAQ behavior
- practical info treatment
- responsible boundaries

Variable:
- artwork
- accent distribution
- page-specific narrative
- specific FAQ
- specific practical details
- specific safeguards

## Recommended page skeleton

1. Hero / universe identity
2. Plain-language explanation
3. Situations / who it can speak to
4. How it works / practical flow
5. Laure's posture/expertise relevant to this offer
6. Practical modalities
7. Responsible boundaries
8. FAQ
9. Closing booking CTA
10. Cross-links to the other accompaniments

Do not force a section if the client source does not support enough real content.

## Hero

Job:
identify the accompaniment immediately and connect it to its universe.

Content:
- animal + element as secondary identity
- H1 = clear accompaniment name
- short plain-language purpose statement
- optional primary CTA: **Prendre rendez-vous**
- original artwork

Layout:
- asymmetric editorial split
- copy first in source order
- artwork second
- avoid generic hero card

Do not:
- lead with mystical terminology before explaining the service
- use vague one-word H1 solely for aesthetics

## Explanation section

Job:
answer “de quoi s'agit-il ?”

Use:
- 2–4 short paragraphs
- one highlighted client belief/position if useful

Avoid:
- pseudo-scientific claims
- promises
- invented methodology

## Situations / audience

Use a scannable editorial list.

Not:
- diagnosis grid
- “symptom -> treatment” mapping
- quiz output

Each item should describe a visitor situation in neutral language.

## How it works

Only use ordered steps when the client process is actually known.

Unknown details remain TODO, not invented.

Pattern:
- 3–5 steps maximum
- vertical timeline on mobile
- no excessive animation

## Laure / expertise

Only show credentials relevant to that accompaniment.

Use real:
- training
- experience
- approach
- values

Never create authority badges/certifications not supplied.

## Practical information

Can include when confirmed:
- remote / in-person
- evening / Saturday availability
- duration
- preparation
- individual/group
- price
- cancellation conditions

Unknown items remain omitted.

## Boundaries

Page-specific safeguards must be visible near the service explanation/practical content.

Medical/veterinary boundaries:
- no diagnosis
- no replacement for competent professionals

For grief/deceased content:
- respectful/non-sensational framing
- no certainty/guarantee claims

## FAQ

4–6 page-specific questions.

Use accessible accordion or open list depending answer length.

Schema ownership must remain technically coherent with Rank Math/custom Structured FAQ.

## Booking close

One primary CTA:
**Prendre rendez-vous**

Optional secondary:
**Contact**

No multiple synonyms for the same booking action.

Routes:
`/prendre-rendez-vous/`

If service preselection can be passed safely to Timetics, keep that context.

## Cross-navigation

At page bottom:
“Découvrir les autres accompagnements”

Use 3 compact links/gateways, not another huge 4-door section.

Current page is excluded.

## Visual variation by universe

Communication animalière:
- Leaf green / Cream / Ink
- squirrel / living earth

Énergétique animalier:
- Antique gold / Ink / Paper
- phoenix / fire

Connexion avec les défunts:
- Moulin blue / Teal / Paper
- turtle / water/family

Guidance pour soi:
- Lavender / Ink / Paper
- butterfly / air/messenger

These are accent distributions within the approved palette, not separate themes.

## Accessibility

- semantic headings
- source order = reading order
- 44px+ controls
- no information on hover only
- reduced motion
- alt text for meaningful artwork; decorative crops hidden appropriately
- no contrast loss from light accent backgrounds

## SEO handoff

Before final copy:
- validate primary search intent
- write unique title/meta
- H1 must be explicit
- maintain hub -> detail -> booking internal links
- avoid keyword stuffing
- do not make health/medical claims for search traffic
