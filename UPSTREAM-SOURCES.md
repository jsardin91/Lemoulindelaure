# Upstream Sources and Attribution

## UI UX Pro Max

Project:
https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

License:
MIT

Official current CLI package documented by upstream:
`ui-ux-pro-max-cli`

Project-local initialization:
- `uipro init --ai codex`
- `uipro init --ai claude`

The upstream project contains its own SKILL.md, searchable datasets, Python search/design-system
scripts, and platform-specific templates.

This pack does not claim ownership of UI UX Pro Max. The bootstrap retrieves/installs the
upstream skill using its official CLI.

## Anthropic Frontend Design

Reference/inspiration:
https://github.com/anthropics/claude-code/blob/main/plugins/frontend-design/skills/frontend-design/SKILL.md

The custom `frontend-design-pro` skill in this pack is an independently written synthesis tailored
for cross-agent use, brand preservation, WordPress, responsive design, accessibility, performance,
and production review. It is not presented as the Anthropic skill.
