# Example Prompts for Agents

These are examples, not mandatory phrasing.

## Existing section improvement

> Improve this hero in EVOLVE mode. Read the active design system and existing page first.
> Preserve the brand. Use Frontend Design Pro and UI UX Pro Max only as supporting intelligence.
> Implement the smallest coherent change, then visually review desktop and mobile.

## Full redesign

> Redesign this page in REDESIGN mode. First inspect the current site, active brand rules,
> and page purpose. Explore a few relevant UI UX Pro Max references, choose one coherent
> art direction, explain the thesis briefly, implement it, then run the visual QA loop.

## New website

> Use the design brief to establish a draft design system before coding.
> Use UI UX Pro Max to research relevant patterns, but do not accept generated palette/font
> choices automatically. Create a distinctive brand-specific thesis, then build the homepage.

## WordPress patch

> Work in EVOLVE mode. Inspect the Astra child theme and current CSS before editing.
> Do not modify core. Preserve typography and SEO behavior. Make the smallest reusable fix,
> validate PHP if touched, account for cache, and review at 375/768/1024/1440.

## UX audit

> Audit this page using Frontend Design Pro plus UI UX Pro Max. Separate:
> 1) brand/design coherence,
> 2) UX/accessibility,
> 3) responsive behavior,
> 4) performance risk,
> 5) implementation maintainability.
> Prioritize changes instead of redesigning everything.
